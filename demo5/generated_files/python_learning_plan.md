# Python 学习计划

## 第一阶段：基础入门（第1-2周）

- **Python 环境搭建**：安装 Python、配置 IDE（推荐 VS Code 或 PyCharm）
- **基本语法**：变量、数据类型（int、float、str、bool）、输入输出
- **运算符**：算术运算符、比较运算符、逻辑运算符
- **流程控制**：`if` / `elif` / `else` 条件判断
- **循环结构**：`for` 循环、`while` 循环、`break` 和 `continue`

## 第二阶段：核心数据结构（第3-4周）

- **字符串操作**：切片、格式化、常用方法
- **列表与元组**：增删改查、列表推导式
- **字典与集合**：键值对操作、集合运算
- **函数**：定义函数、参数传递、返回值、作用域

## 第三阶段：进阶内容（第5-6周）

- **文件操作**：读写文件、`with` 语句
- **异常处理**：`try` / `except` / `finally`
- **模块与包**：导入模块、自定义模块、`pip` 包管理
- **面向对象编程**：类与对象、继承、封装、多态

## 第四阶段：实用技能（第7-8周）

- **常用标准库**：`os`、`sys`、`datetime`、`json`、`re`
- **第三方库入门**：`requests`（网络请求）、`pandas`（数据处理）
- **简单项目实战**：爬虫小项目、数据分析小项目

## 学习建议

- 每天坚持编码至少 30 分钟
- 多动手写代码，不要只看不练
- 善用官方文档和社区资源（Stack Overflow、GitHub）
- 每学完一个知识点，尝试自己写一个小例子巩固
