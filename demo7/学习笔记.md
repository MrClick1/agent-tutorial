## Runtime 继承与方法重写练习

完成日期：2026-10-12。lesson_08_runtime_inheritance.py 通过 3/3 项检查。

CodingAgentRuntime 继承 AgentRuntime，复用主循环，并重写 create_state 定制代码任务状态。先用 super().create_state(goal) 获取通用状态，再向 shared_context 添加 workspace_dir，最后返回状态。

练习通过 state["shared_context"]["workspace_dir"] = "project_workspace" 添加字段，不替换整个 shared_context，因此可以保留父类今后加入的其他上下文字段。原项目当前父类返回空 shared_context，直接赋一个新字典也能得到相同结果。

父类方法中的 self 仍指向实际子类实例，所以继承的 start（项目中为 run）调用 self.create_state(goal) 时，会使用子类重写的方法。super() 是内置功能，此处用于复用父类实现，不需要导包。

本次检查覆盖父类字段保留、父类行为不受影响、继承方法调用子类实现及不同任务状态独立。下一步学习 Coding Agent 的代码观察与精确修改工具；本练习完成不代表 demo7 全部完成。

## 代码搜索工具练习复盘

完成日期：2026-10-13。lesson_09_search_code.py 的多文件命中、行号、无法按 UTF-8 解码的文件跳过及无命中结果检查全部通过。

Coding Agent 先搜索定位文件和行号，再读取目标代码，最后决定是否修改。search_text 的流程是：rglob 遍历目录、过滤文件、读取文本、逐行匹配关键词、返回路径与行号。

```python
for line_number, line in enumerate(text.splitlines(), start=1):
    if query in line:
        matches.append({
            "relative_path": path.relative_to(workspace).as_posix(),
            "line_number": line_number,
            "line": line,
        })
```

splitlines 按顺序拆出每行，enumerate 为元素附上从 1 开始的编号。循环变量分别接收编号和行内容，因此编号对应文件行号。直接遍历 splitlines 不会自动获得行号。

例如 workspace 为 D:/project，path 为 D:/project/sub/utils.py，relative_to(workspace) 得到表示 sub/utils.py 的 Path 对象，as_posix() 将其转换成用 / 分隔的字符串。此转换不移动文件。原项目使用 str(path.relative_to(WORKSPACE_DIR)).replace("\\", "/") 实现同样的路径表示。

工具结果包括 ok、query、matches、match_count 和 context_updates。context_updates 保存 last_search_query，供 Runtime 合并到任务状态；详细命中结果通过工具消息供模型查看。

练习由调用方提供测试目录，简化了原项目的路径边界校验和 @tool 注册，不代表已实现路径安全控制。后续学习 resolve_safe_path 与精确替换工具。

## 路径校验与精确替换工具复盘

完成日期：2026-10-13。lesson_10_replace_code.py 的次数不符不写入、正确替换、越界路径拒绝、目标不存在及旧文本未命中检查全部通过。

修改工具的流程：resolve_safe_path 校验并解析目标路径，检查目标是文件，读取 original，用 count 核对旧文本出现次数；符合 expected_occurrences 才 replace，并通过 write_text 写回。

路径解析将工作区与相对路径拼接后 resolve，再检查目标仍位于工作区。它不读取文件、不保证文件存在；is_file 负责后续文件检查。这种检查是演示级路径控制，并非对所有并发文件系统变化的隔离保证。

count 统计非重叠出现次数；replace 返回新字符串，不修改原字符串，也不理解 Python 语法。因此 timeout = 10 在注释中出现也会计数与替换，次数校验能减少意外修改，但不能证明代码语义正确。

结果字段必须与调用方约定一致，本次将 replace_occurences 修正为 replaced_occurrences 后通过完整检查。context_updates 记录 last_modified_relative_path。

练习额外检查旧文本非空、预期次数为正整数，并在临时目录中验证真实文件内容，不修改项目业务文件。下一步把观察工具、修改工具与 CodingAgentRuntime 串起来，理解完整任务执行及验证边界。
