# demo7 学习笔记

## 回答问题

- <code>给 greet_user 增加空名字处理</code>：当前 project_workspace/utils.py 已经包含空名字判断，空字符串会返回 “Hello, friend! It's nice to meet you!”。因此这个练习在当前代码中已经完成。复盘正确链路应是先用 search_text 定位 greet_user，再用 read_text_file 确认实现；发现需求已满足后应停止修改并报告，不应该为了“完成任务”重复改代码。

- <code>把 DEFAULT_THEME 从 light 改成 dark</code>：应先通过 search_text 或 search_files_by_name 定位 settings.py，读取文件确认只有一个目标，再使用 replace_text_in_file，将 DEFAULT_THEME = "light" 精确替换为 DEFAULT_THEME = "dark"，expected_occurrences 设为 1。修改后应重新读取文件验证，而不是仅相信写工具返回成功。

- <code>定位业务逻辑并总结</code>：可以搜索 calculate_discount。当前逻辑位于 utils.py：VIP 用户折扣率为 10%，非 VIP 为 2%，函数返回 price * (1 - discount)。这是只读任务，使用搜索和读取工具即可，不应调用修改工具。

## 总结

demo7 在 demo6 框架上实现最小 Coding Agent，核心行为是先观察、再定位、再读取、最后精确修改。coding_tools 将工具分成观察型与修改型，用工作区沙箱限制访问范围，并通过 expected_occurrences 防止误替换。真正成熟的 Coding Agent 还需要 diff、语法检查、测试、版本控制和回滚。
